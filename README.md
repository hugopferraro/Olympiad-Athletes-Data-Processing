# Tratamento de dados de atletas olímpicos

Ingestão, diagnóstico, limpeza e validação do conjunto de dados
**120 years of Olympic history: athletes and results**.

O tratamento remove registros duplicados, preenche idades ausentes com a média,
remove registros sem altura e preenche pesos ausentes por medianas de sexo e
modalidade. O resultado possui 210.917 registros completos nas variáveis
`Age`, `Height` e `Weight`.
